Google Drive backups

Connect your Google account to save progress, review schedules, settings, themes and uploaded backgrounds in a dedicated Drive folder. API keys are excluded. Backups are private to your Drive, but not encrypted by this app.

Automatic backups require this app to be open and Google access to be valid. Google access expires (usually in about an hour); reconnect when prompted. Missed backups run when you return and reconnect. Restoring replaces this device’s data. This is not live multi-device sync.

Setup guide for GitHub Pages

When a limit is selected, only older unpinned backups are moved to Drive trash after a successful upload. Manual and legacy backups are pinned by default. Pin/unpin individual files in history. This includes unpinned checkpoints from other devices.

Quick save skips unchanged data and updates the latest quick-save checkpoint when safe. Manual backups stay separate. If progress or media would be removed, a new checkpoint preserves the previous copy (subject to your retention limit). Connecting Google only checks your saves.

Recovery, privacy & connection help

Before every restore, a recovery copy is saved on this device. Restore stops if that copy cannot be stored. Undo restores the previous state, not a merge; later changes will be replaced. Recovery copies are not uploaded and exclude API keys.

Disconnecting keeps local progress and cloud files. Deleting local data removes progress, settings, local API keys, media, backups and recovery data only on this device. Deleting cloud backups moves this app’s files to Drive trash, including pinned copies, without clearing local progress.

Backups contain progress, review schedules, settings, themes, avatar and AI cached responses. They are not app-encrypted. API keys and Google tokens are excluded. Anyone with a downloaded JSON copy can read its contents.
